TheCawa's Dev Space

A curated collection of open-source software engineering projects, experiments, and developer tools.

  • CawOS

    A multifunctional 32-bit operating system for x86 (i686) architecture, written from scratch in C and Assembly. Features a custom bootloader, pre-emptive multitasking, custom file system (CawFS), and a GUI desktop.

  • DRP (Drowning Rat Protocol)

    A lightweight, application-layer transport protocol built for aggressive, persistent retransmission and guaranteed message delivery over high-loss channels.

  • noveng

    A lightweight and high-performance visual novel script engine written in C++17, featuring automated saves, internal variable processing, and custom UI elements.

  • IST

    A dedicated emulator, development toolkit, and documentation repository focusing on custom processor architecture simulation.
